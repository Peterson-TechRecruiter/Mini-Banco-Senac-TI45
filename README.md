# Mini-Banco-Senac-TI45
**Projeto de Mini Banco realizado nas aulas do curso Técnico em Informática período noturno no Senac São Carlos baseado no livro Think Java Ed 02.**

## Funcionalidades
-**cadastro de clientes**
-**registro de transações bancarias (depósitos, saques e transferências)**
-**geração de extratos em tempo real.**

## Tecnologias utilizadas
-**Programa 100% elaborado em Java.**
-**programa 100% elaborado no VSCode.**

## Estrutura do projeto
\
|**menu          # Identificação do usuário e navegação entre as opções do banco.**
|**opção 1       # Inicia as ações para depositar um valor.**
|**opção 2       # Inicia a ação de saque de valores depositados anteriormente.**
|**opção 3       # Exibe o Saldo atual da conta do usuário.**
|**opção 3       # Exibe o Extrato da conta do usuário.**
|**opção 4       # Finaliza o programa atual.**
